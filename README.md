# Портфолио Кирилла

Адаптивный сайт-портфолио на HTML, CSS и обычном JavaScript. Дизайн: **Nordic Lagom Corporate Minimalism** (вариант № 1).

## Файлы проекта

- `index.html` — содержание и структура страниц.
- `style.css` — цвета, шрифты, расположение блоков и мобильная адаптация.
- `script.js` — мобильное меню и автоматическое обновление года.

## Как открыть сайт

1. Скачайте или распакуйте папку проекта.
2. Откройте `index.html` в браузере.
3. Для редактирования откройте папку в Visual Studio Code.

Сборка, установка npm-пакетов и сервер не нужны. Шрифты загружаются из Google Fonts; при отсутствии интернета используются системные запасные шрифты.

## Как изменить содержание

Откройте `index.html` и найдите нужный раздел по комментариям и заголовкам:

- имя и описание — блок `hero`;
- информация о себе — `about`;
- образование — `education`;
- навыки — `skills`;
- проекты и практика — `projects`;
- цели — `goals`;
- контакты — `contacts`.

Чтобы добавить ссылку на проект, разместите её только после того, как появится реальная публичная ссылка. Не указывайте личный телефон или Telegram без отдельного решения.

## Публикация на GitHub Pages

1. Создайте новый репозиторий GitHub.
2. Загрузите в него `index.html`, `style.css`, `script.js` и `README.md`.
3. Откройте **Settings → Pages**.
4. В разделе публикации выберите ветку `main` и папку `/ (root)`.
5. Сохраните настройки. После обработки GitHub покажет адрес сайта.

Публикация не выполняется автоматически. Перед загрузкой проверьте, что в проекте нет личных данных, которые вы не хотите показывать публично.

## Приватность и точность

Телефон и Telegram не опубликованы. Даты обучения, ссылки на проекты, награды и результаты конкурса не добавлялись, поскольку подтверждённые сведения отсутствуют. Декоративные иллюстрации сделаны средствами CSS и не выдаются за фотографии или реальные скриншоты работ.
